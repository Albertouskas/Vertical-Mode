# Vertical-Mode

Analysis of the streets of Madrid to find the best route for maximizing altitude gain (desnivel) on foot.

## About the event

[Vertical Mode](https://degensrunclub.com/vertical-mode) is a DEGENS × Chia event held on Friday, 20 November 2026 in Madrid.

- **Format:** one hour of uphill running or walking through the streets of Madrid, in teams of three.
- **Teams:** each team has a single barometric altimeter watch that is passed between members. Everyone brings their own watch in case one fails.
- **Schedule:** start at 19:30 and finish at 20:30, both at the Chia door (C. de Orense, 70, Tetuán).
- **Route:** there is no fixed route or checkpoints. Teams choose freely (stairs, long hills, etc.).
- **Scoring:** the official elevation gain is calculated by the organizers from the uploaded watch files, using the same method for all teams. Arriving late costs 15 m of elevation per minute. Ties are broken by the shorter distance covered.
- **Rules:** on foot and in public space only. No metro, bike, scooter, elevator or escalators.

This repository explores the same problem with open data: it builds Madrid's pedestrian graph from OpenStreetMap, samples elevation from the PNOA 5 m terrain model, and ranks streets by altitude and estimated uphill gain. It also highlights mapped stairs, footways, paths, and pedestrian streets near the event start.

## Requirements

### Software

- Python 3.10 or newer
- Jupyter / VS Code with the Jupyter extension
- [uv](https://docs.astral.sh/uv/) (recommended) or pip

### Python packages

| Package | Used for |
|---------|----------|
| `pandas` | Tabular data handling |
| `osmnx` | Fetching the Madrid municipality boundary from OpenStreetMap |
| `pyrosm` | Reading the local `.osm.pbf` file and building the walking network |
| `geopandas` | Geometry operations and CRS transforms |
| `shapely` | Geometry dependency |
| `pyproj` | CRS transformations |
| `rasterio` | Reading the elevation raster |

Install them with:

```bash
uv pip install pandas osmnx pyrosm geopandas shapely pyproj rasterio
```

### Data files

Place these files in the repository root before running the notebook:

- `madrid-261103.osm.pbf`: OpenStreetMap extract used for the pedestrian graph. Download a current extract from [Geofabrik](https://download.geofabrik.de/europe/spain.html).
- `PNOA_MDT05_ETRS89_HU30_*_LID.tif`: PNOA MDT05 tiles from the [Centro de Descargas del CNIG](https://centrodedescargas.cnig.es/CentroDescargas/index). Place the tiles in the project folder; the notebook mosaics matching files automatically.

The notebook reads the local `.pbf` and downloads the Madrid municipality boundary through OSMnx. A network connection is required to fetch that boundary.

**Coverage matters:** the currently available `0559` raster is only one DEM tile and does not cover all of Madrid or the complete 5 km circle around Calle de Orense, 70. Until additional tiles are added, elevation rankings only include the streets inside the supplied tile coverage. The notebook prints coverage percentages so partial rankings are visible.

`elev_mean` is average altitude above sea level, not elevation gain. The notebook also estimates uphill gain in both street directions from the sampled elevation profile; use it to identify candidate segments, not as a substitute for the event watch's barometric score. OSM stairs and access tags can be incomplete, so verify that candidate paths are public and usable.

## Usage

1. Install the requirements and place the data files as described above.
2. Open `Vertical_Mode_Experiments.ipynb` and run the cells in order.
3. The notebook prints the highest-altitude streets in DEM-covered Madrid, the same ranking within 5 km of the start, and nearby climb/stair candidates.
4. The final cell writes `calles_altitud_madrid.gpkg` plus CSV rankings for Madrid altitude, the local 5 km altitude ranking, climb candidates, and mapped stairs.
