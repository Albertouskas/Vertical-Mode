# Vertical-Mode

Analysis of the streets of Madrid to find the best route for maximizing altitude gain (desnivel) on foot.

## About the event

[Vertical Mode](https://degensrunclub.com/vertical-mode) is a DEGENS × Chia event held on Friday, 20 November 2026 in Madrid.

- **Format:** one hour of uphill running or walking through the streets of Madrid, in teams of three.
- **Teams:** each team has a single barometric altimeter watch that is passed between members. Everyone brings their own watch in case one fails.
- **Schedule:** start at 19:30 and finish at 20:30, both at the Chia door (C. de Orense, 70, Tetuán).
- **Route:** there is no fixed route or checkpoints. Teams choose freely (stairs, long hills, etc.).
- **Scoring:** the official elevation gain is calculated by the organizers from the uploaded watch files, using the same method for all teams. Arriving late costs 15 m of elevation per minute. Ties are broken by the shorter distance covered.
- **Rules:** on foot and in public space only. No metro, bike, scooter, elevator or escalators.

This repository explores the same problem with open data: it builds a walking graph of Madrid from OpenStreetMap, samples elevation along each street, and ranks streets by altitude and slope.

## Repository contents

| File | Description |
|------|-------------|
| `Vertical_Mode_Experiments.ipynb` | Main notebook: graph loading, elevation sampling, slope and score calculation, export to GeoPackage |
| `madrid-261025.osm.pbf` | OpenStreetMap extract of Madrid (input for the local graph) |
| `PNOA_MDT05_ETRS89_HU30_0559_LID.tif` | PNOA MDT05 elevation raster (ETRS89 / UTM 30N) used for elevation values |
| `calles_altitud_madrid.gpkg` | Output: streets with elevation statistics (generated by the notebook) |
| `LICENSE` | Repository license |

## Requirements

### Software

- Python 3.10 or newer
- Jupyter / VS Code with the Jupyter extension
- [uv](https://docs.astral.sh/uv/) (recommended) or pip

### Python packages

| Package | Used for |
|---------|----------|
| `pandas` | Tabular data handling |
| `osmnx` | Online graph download (used when `USAR_ARCHIVO_LOCAL = False`) |
| `pyrosm` | Reading the local `.osm.pbf` file and building the walking network |
| `geopandas` | Geometry operations and CRS transforms |
| `shapely` | Geometry dependency |
| `pyproj` | CRS transformations |
| `rasterio` | Reading the elevation raster |
| `rasterstats` | Zonal statistics over the raster |

Install them with:

```bash
uv pip install pandas osmnx pyrosm geopandas shapely pyproj rasterio rasterstats
```

### Data files

Place these files in the repository root before running the notebook:

- `madrid-261025.osm.pbf`: OpenStreetMap extract for Madrid. Download from [Geofabrik](https://download.geofabrik.de/europe/spain.html) or extract from [OpenStreetMap](https://www.openstreetmap.org/).
- `PNOA_MDT05_ETRS89_HU30_0559_LID.tif`: PNOA MDT05 tile covering the study area, from the [Centro de Descargas del CNIG](https://centrodedescargas.cnig.es/CentroDescargas/index).

The notebook reads the local `.pbf` by default. To download the graph from the OpenStreetMap API instead, set `USAR_ARCHIVO_LOCAL = False` in the graph cell. The API can be slow or rate-limited.

## Usage

1. Install the requirements and place the data files as described above.
2. Open `Vertical_Mode_Experiments.ipynb` and run the cells in order.
3. The final cell writes `calles_altitud_madrid.gpkg`, which can be opened in QGIS or any GIS tool.
